# v0.9.0：Coding Agent

## 总述

v0.8.0 的 Agent 能读工作区，但不能改，也不能跑命令。这一版补上 `writeFile` 和 `runCommand`，同时加上权限门：只读工具可以直接执行，有副作用的工具必须先等人批准。任务因此会在 `running` 和 `waiting` 之间暂停、恢复。

```text
           Agent          Tool
                ↓
           Task Runtime
                ↓
      MCP      Skills     Approval
```

本版新加的层是 Approval，和 MCP、Skills 并列，都由 Task Runtime 使用。写文件和执行命令会先落到 Approval；只读 Tool 仍然直接执行。

### 从 v0.8.0 转变了什么

保留：

- SSE、Tool Resolver、技能、只读文件工具和路径沙箱。
- 本地工具 `searchKnowledge`、`getCurrentTime` 仍然是 `allow`，不会突然要求审批。

改变：

- 工具执行前多一道权限判断。Resolver 交出的 ToolSet 会被包一层；Loop 本身仍然只调用 `execute`，不知道外面有审批。
- 状态机里的 `waiting` 被用起来：`running → waiting → running`，或者 `waiting → cancelled`。
- 读文件和搜索也会跳过敏感路径。工作区内部不再等于全部可读。

新增：

- `writeFile`：在沙箱内创建或覆盖文本文件，限制体积，父目录不存在时会创建。
- `runCommand`：只接受 `{ program, args }`，用 `execFile` 而不是 shell。程序只允许 `pnpm` / `npm` / `npx` 的开发命令组合，工作目录必须在工作区内，并拒绝 `rm`、管道、重定向这类 token。
- 审批对象和 API：`GET /api/agent/tasks/:taskId/approvals`，以及按 approval id 提交批准或拒绝。
- `coding` 技能，描述读、分析、修改、测试、再修的顺序。
- `/api/health`，作为一次真实编码任务的落点。

### 这一版还没有

- 审批和工具耗时的事后档案。SSE 里看得到 `approval.required`，连接断开后没有聚合 Trace。
- 自动评估脚本。

## 工作流

1. 任务开始时，Runtime 先拿到 Resolver 的工具集，再按工具名包上权限门。未知工具默认需要审批。
2. 模型若调用 `listFiles`、`readFile`、`searchFiles`、`searchKnowledge` 或 `getCurrentTime`，门直接放行。
3. 模型若调用 `writeFile` 或 `runCommand`，Runtime 创建一条 `pending` 的 Approval，任务从 `running` 转到 `waiting`，并发出 `approval.required`。事件里的入参是摘要：写文件只给路径和内容长度，命令只给 program、args 和 cwd，不把文件全文推给订阅者。
4. Loop 停在这个工具的 `execute` 上，等待决定。
5. 批准后，任务回到 `running`，发出 `approval.approved`，原来的 `execute` 才真正写文件或跑命令。结果回到模型，模型可以继续下一步。
6. 拒绝后发出 `approval.rejected`，任务转到 `cancelled`，并发出 `task.cancelled`。Runtime 中止这次 Loop，工具返回「被用户拒绝」，且不会把任务再标成 `completed`。
7. 只有任务仍是 `running` 时，结束阶段才会写成 `completed`。已经取消或失败的任务不会被收尾逻辑改掉。

写和执行还有第二层限制，审批通过也不越过它们：路径必须在工作区根下，敏感文件（`.env*`、密钥、`.ssh`、`.aws`、`.config`、`.git`）拒绝读写和搜索；命令必须落在白名单里。

## 分层

```text
streamAgent
  → Permission Gate
      → allow：原工具
      → approval_required：Approval Store + 状态机 waiting
          → 原工具（writeFile / runCommand）
```

| 层 | 职责 | 位置 |
| --- | --- | --- |
| 策略 | 工具名到 allow / approval_required | `src/lib/agent/permission.ts` |
| 审批 | 创建、等待、批准、拒绝 | `src/lib/agent/approvals.ts` |
| 门 | 包住工具并改任务状态 | `src/lib/agent/task/runtime.ts` |
| 写文件 | 沙箱内写入 | `src/lib/mcp/filesystem/core.ts` |
| 命令 | 白名单和 execFile | `src/lib/mcp/command/core.ts` |
